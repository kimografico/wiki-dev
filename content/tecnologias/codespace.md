## Qué es

Entorno de desarrollo alojado en la nube que se crea a partir de un repositorio.

## Para qué sirve

Permite abrir el proyecto ya configurado desde cualquier equipo sin instalar dependencias locales.

## Cuándo usarla

Úsalo cuando trabajas desde otro ordenador o necesitas un entorno reproducible.

## Cuándo no

No sustituye al entorno local si dependes de herramientas gráficas concretas.

## Alternativas

No hay una alternativa directa dentro del catálogo: la decisión depende del requisito concreto.

## Ejemplo

Abrir el repo en GitHub Codespaces y ejecutar `npm run dev` directamente.
