## Qué es

Familia de bibliotecas de código abierto para estado asíncrono, rutas, tablas y formularios.

## Para qué sirve

Resuelve necesidades habituales de aplicaciones React con una API consistente entre paquetes.

## Cuándo usarla

Conviene cuando ya usas React y quieres una solución probada para datos remotos o tablas complejas.

## Cuándo no

No es un framework completo: se integra dentro de la aplicación, no la controla.

## Alternativas

No hay una alternativa directa dentro del catálogo: la decisión depende del requisito concreto.

## Ejemplo

TanStack Query para datos del servidor y TanStack Table para una tabla con filtros.
