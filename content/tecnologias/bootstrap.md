## Qué es

Framework de CSS con componentes y utilidades listas para construir interfaces responsive.

## Para qué sirve

Da una base visual coherente sin diseñar cada botón, tabla o rejilla desde cero.

## Cuándo usarla

Úsalo para prototipos, paneles internos o proyectos que necesitan salir rápido con un aspecto aceptable.

## Cuándo no

No es la mejor opción cuando el diseño tiene un sistema visual propio muy específico.

## Alternativas

Las alternativas directas son `tailwindcss`. Conviene compararlas antes de elegir.

## Ejemplo

```html
<div class="container"><button class="btn btn-primary">Guardar</button></div>
```
