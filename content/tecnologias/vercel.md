## Qué es

Plataforma de despliegue orientada a aplicaciones web con integración estrecha con frameworks como Next.js.

## Para qué sirve

Publica cada rama en una URL propia y gestiona build, caché y funciones serverless.

## Cuándo usarla

Úsala cuando el equipo trabaja con Next.js y quiere preview por pull request.

## Cuándo no

No es la opción natural para una wiki estática que ya se publica en GitHub Pages.

## Alternativas

Las alternativas directas son `github-pages`. Conviene compararlas antes de elegir.

## Ejemplo

Un pull request que genera una URL de vista previa antes de fusionarse.
