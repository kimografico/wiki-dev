## Qué es

Plataforma de repositorios Git de Atlassian con control de acceso, pull requests y pipelines propios.

## Para qué sirve

Aloja el código y conecta cambios, revisiones y despliegues dentro del ecosistema Atlassian.

## Cuándo usarla

Conviene cuando Jira y el resto del equipo ya usan productos Atlassian.

## Cuándo no

No aporta ventaja si todo el flujo de CI y documentación está en GitHub.

## Alternativas

Las alternativas directas son `github`, `gitlab`. Conviene compararlas antes de elegir.

## Ejemplo

Una rama con un pull request que ejecuta Bitbucket Pipelines antes de fusionarse.
