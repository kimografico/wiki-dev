## Qué es

Servidor de integración y despliegue continuo de Atlassian que ejecuta planes de build y release.

## Para qué sirve

Automatiza compilación, tests y publicación, y se integra con Jira y Bitbucket.

## Cuándo usarla

Úsalo cuando el equipo ya vive en el ecosistema Atlassian y quiere un único lugar para planes y trazas.

## Cuándo no

Evítalo si el proyecto es pequeño y una acción de GitHub cubre lo mismo con menos configuración.

## Alternativas

Las alternativas directas son `github`, `gitlab`. Conviene compararlas antes de elegir.

## Ejemplo

Un plan que compila, ejecuta tests y publica el artefacto tras cada push.
