## Qué es

Plataforma de repositorios Git con CI, registros de paquetes y gestión de proyectos integrada.

## Para qué sirve

Cubre todo el ciclo desde el repositorio hasta el despliegue en una sola herramienta.

## Cuándo usarla

Úsala cuando se quiere un flujo DevSecOps completo en una plataforma única.

## Cuándo no

No aporta ventaja frente a GitHub si allí ya están las issues y Actions.

## Alternativas

Las alternativas directas son `github`, `bamboo`. Conviene compararlas antes de elegir.

## Ejemplo

Un pipeline de GitLab que compila, testea y publica una imagen.
