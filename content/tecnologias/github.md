## Qué es

Plataforma de alojamiento de repositorios Git que añade pull requests, issues y Actions.

## Para qué sirve

Es el lugar donde se revisa el código, se discuten cambios y se ejecuta la automatización del proyecto.

## Cuándo usarla

Conviene cuando el equipo quiere integrar código, revisión y CI en un mismo sitio.

## Cuándo no

No es Git: si falla la plataforma, el historial local sigue intacto.

## Alternativas

Las alternativas directas son `gitlab`, `bamboo`. Conviene compararlas antes de elegir.
