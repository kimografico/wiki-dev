## Qué es

D3 (Data-Driven Documents) es una biblioteca de JavaScript para construir visualizaciones conectando datos con el DOM. No es una librería de gráficos: no te da un objeto al que pasarle opciones y listo. Te da bloques pequeños —selecciones, escalas, ejes, formas, transiciones— que tú combinas para dibujar exactamente lo que necesitas. Cada módulo se puede importar por separado (`d3-scale`, `d3-shape`, `d3-color`…), así que puedes usar solo la pieza que resuelve tu problema.

## Para qué sirve

Sirve cuando un gráfico estándar se queda corto: necesitas una interacción concreta, una escala no lineal, una anotación pegada a un punto o un layout de red. Un caso reconocible: un panel que resalta al pasar el ratón un segmento y muestra un *tooltip* con el dato exacto, con una paleta coherente. D3 te deja decidir cada paso: del dato a la posición en píxel, de la posición al elemento SVG.

## Cuándo usarlo

- Cuando la visualización es a medida y vas a mantenerla: el coste de construirla se amortiza si el diseño es estable.
- Cuando necesitas control fino sobre escalas, ejes o interacción y ninguna opción de una librería de configuración lo cubre.
- Cuando solo necesitas una utilidad suelta —interpolar colores, generar una curva— y puedes importar el módulo correspondiente.

## Cuándo no

- Si te basta un gráfico de barras o líneas con opciones: una librería de gráficos lo resuelve en menos código y con menos mantenimiento.
- Si el equipo no va a dedicar tiempo a entender SVG y escalas: D3 exige esos conceptos.
- Si solo quieres un diagrama de flujo o de secuencia a partir de texto: Mermaid está pensado para eso, no D3.

## Matices

D3 no decide por ti cómo se pinta la aplicación: en una interfaz con React lo habitual es que D3 calcule escalas, formas e interpolaciones mientras React renderiza el SVG. Conviene no mezclar ambos manipulando el mismo nodo del DOM. El módulo `d3-color` se encarga solo de espacios de color e interpolaciones; se usa cuando no necesitas el resto de D3. Tampoco conviene confundir D3 con una librería de gráficos: aquí no hay un `chart` configurable, hay primitivas que ensamblas tú.

## Ejemplo

```js
import { scaleLinear, line } from "d3";

const escala = scaleLinear().domain([0, 100]).range([0, 300]);
const trazado = line()
  .x((valor, indice) => escala(indice * 20))
  .y((valor) => 150 - escala(valor));

const ruta = trazado([10, 35, 60, 25]); // cadena lista para <path d={ruta}>
```

La escala convierte el dominio de datos en píxeles; el generador de línea convierte la serie en un `path` de SVG.
