## Qué es

Biblioteca para crear visualizaciones de datos mediante selección de elementos y transformación de documentos.

## Para qué sirve

Da control total sobre escalas, ejes y formas cuando un gráfico de configuración no basta.

## Cuándo usarlo

Conviene para visualizaciones a medida con interacción específica.

## Cuándo no

No es Chart.js: D3 exige construir el gráfico; una librería de gráficos lo genera a partir de opciones.

## Alternativas

No hay una alternativa directa dentro del catálogo: la decisión depende del requisito concreto.

## Ejemplo

```js
const escala = d3.scaleLinear().domain([0, 100]).range([0, 300]);
```

### d3-color

El módulo `d3-color` se encarga solo de espacios de color e interpolaciones; se usa cuando no necesitas el resto de D3.
