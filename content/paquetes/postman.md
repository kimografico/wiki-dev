## Qué es

Cliente de API con interfaz gráfica, entornos y colecciones compartidas para explorar y probar endpoints.

## Para qué sirve

Permite probar peticiones, guardar ejemplos y compartirlos con el equipo.

## Cuándo usarlo

Úsalo cuando quieres explorar una API de forma interactiva o documentar respuestas para otros.

## Cuándo no

No es la mejor opción si el equipo quiere las peticiones versionadas como texto en Git.

## Alternativas

Las alternativas directas son `bruno`. Conviene compararlas antes de elegir.

Una colección con la petición de acceso y un entorno con la URL base.
