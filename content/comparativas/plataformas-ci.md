## Contexto

Bamboo, Bitbucket, GitHub y GitLab aparecen juntas al elegir dónde alojar código y ejecutar automatización.

## Criterios

Integración con el resto de herramientas, modelo de pipelines, coste de configuración y trazas.

## Cuándo elegir cada una

GitHub si allí están ya las issues; GitLab para un ciclo completo en una plataforma; Bamboo y Bitbucket si el equipo vive en Atlassian.

## Ejemplos

Un workflow de GitHub Actions frente a un plan de Bamboo que publica el mismo artefacto.
