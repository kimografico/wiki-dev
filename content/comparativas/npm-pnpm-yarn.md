## Contexto

Tres gestores de dependencias que resuelven el mismo problema con decisiones distintas sobre lockfile, disco y workspaces.

## Criterios

Velocidad de instalación, uso de disco, compatibilidad y estructura del lockfile.

## Cuándo elegir cada una

npm por defecto y compatibilidad máxima; pnpm para ahorrar disco y monorepos; Yarn cuando el equipo ya lo usa y valora sus workspaces.

## Ejemplos

```bash
npm install
pnpm install
yarn install
```
