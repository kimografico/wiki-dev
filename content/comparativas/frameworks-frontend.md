## Contexto

React, Vue y Angular resuelven el mismo problema —construir interfaces con estado— con filosofías distintas. La decisión pesa menos por la tecnología en sí que por el equipo, el tamaño del proyecto y cuánta guía se quiere recibir.

## Criterios

- **Filosofía**: React propone un modelo mínimo y deja el resto al ecosistema; Vue adopta un punto medio; Angular ofrece una plataforma completa y opinionada.
- **Curva de aprendizaje**: Vue y React arrancan rápido; Angular pide aprender más conceptos desde el principio.
- **Control y convención**: React máxima libertad, Angular máxima estructura, Vue intermedia.
- **Ecosistema**: los tres tienen comunidades grandes y bibliotecas de sobra.

## Cuándo elegir cada una

Elige **React** si quieres la comunidad más amplia y libertad para componer tu stack. Elige **Vue** si vienes de HTML y buscas una entrada suave con todo lo necesario. Elige **Angular** si el proyecto es grande, largo y prefieres convenciones fuertes y herramientas integradas.

En esta wiki el framework se usa solo para una isla; por eso basta con React, el que ya está integrado.
