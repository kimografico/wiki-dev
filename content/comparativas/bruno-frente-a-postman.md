## Contexto

Dos clientes de API con filosofías distintas sobre dónde viven las peticiones y cómo se comparten.

## Criterios

Almacenamiento, control de versiones, colaboración y curva de uso.

## Cuándo elegir cada una

Bruno conviene si las peticiones deben versionarse como texto en Git; Postman si el equipo quiere entornos y colaboración en la nube.

## Ejemplos

Un repo con archivos `.bru` revisables en PR frente a una colección compartida con variables de entorno.
