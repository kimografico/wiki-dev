## Definición

Proceso que transforma el código fuente en artefactos listos para publicar.

## Por qué importa

Separa lo que se escribe de lo que se despliega: en ese paso pasan compilación, minificación y generación estática.

## Ejemplo

```bash
npm run build
```

## Se confunde con

No es despliegue: el build produce archivos; el despliegue los coloca en un servidor o CDN.
