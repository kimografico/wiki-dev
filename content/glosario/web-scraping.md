## Definición

Extracción automatizada de datos de páginas web mediante peticiones y análisis de su contenido.

## Por qué importa

Sirve para convertir información pública en datos estructurados, con límites legales y técnicos que hay que respetar.

## Ejemplo

Leer tablas públicas de una web y guardarlas como JSON.

## Se confunde con

No es usar una API: cuando existe API oficial, es más estable que parsear HTML.
