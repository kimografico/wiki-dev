## Definición

Maneras acordadas de representar información para intercambiarla: JSON, YAML, CSV y notaciones compactas como TOON.

## Por qué importa

Un formato define qué se puede expresar y cuánto pesa; elegirlo mal encarece cada petición o cada revisión.

## Ejemplo

JSON para APIs, YAML para configuración legible y TOON como notación orientada a tokens para reducir consumo en LLM.

## Se confunde con

No es un protocolo: el formato es la representación; el protocolo define cómo se transporta.
