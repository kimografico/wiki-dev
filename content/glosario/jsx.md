## Definición

Extensión sintáctica de JavaScript que permite escribir etiquetas parecidas a HTML dentro del código.

## Por qué importa

Hace que la estructura de la interfaz sea visible junto a la lógica que la produce.

## Ejemplo

```jsx
const saludo = <h1>Hola, {nombre}</h1>;
```

## Se confunde con

No es HTML: se compila a llamadas de creación de elementos y admite expresiones JavaScript entre llaves.
