## Definición

Proceso de localizar y corregir la causa de un comportamiento inesperado del código.

## Por qué importa

Depurar es observar ejecución real, no adivinar: breakpoints, trazas y consola reducen el espacio de búsqueda.

## Ejemplo

```js
debugger; // el navegador se detiene aquí y permite inspeccionar variables
```

## Se confunde con

No es el paquete npm `debug`: aquí se habla de la práctica general de depuración.
