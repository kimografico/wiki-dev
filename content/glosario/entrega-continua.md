## Definición

Práctica de mantener cada cambio validado en un estado listo para publicarse, con despliegue automatizado o fácilmente disparable.

## Por qué importa

Reduce el tamaño y el riesgo de cada publicación porque se publica con frecuencia y con el mismo proceso.

## Ejemplo

Tras pasar tests y build, el pipeline publica automáticamente en GitHub Pages.

## Se confunde con

No es integración continua: la CI valida cada cambio; la entrega continua se ocupa de que esté listo para el usuario.
