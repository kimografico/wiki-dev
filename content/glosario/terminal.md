## Definición

Programa que abre una sesión de texto con el sistema operativo, normalmente a través de un shell.

## Por qué importa

Es el entorno donde se ejecutan comandos reproducibles de build, lint y Git.

## Ejemplo

```bash
npm run check && npm run validate
```

## Se confunde con

No es el shell: la terminal es la ventana; el shell es el intérprete que ejecuta las órdenes dentro de ella.
