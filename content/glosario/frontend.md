## Definición

El frontend es la parte del software que se ejecuta en el navegador y con la que interactúa directamente la persona usuaria. Comprende el HTML que estructura la página, el CSS que la presenta y el JavaScript que responde a eventos y consulta datos. No incluye lo que ocurre en el servidor, aunque consuma sus respuestas.

## Por qué importa

Es donde se notan los errores de usabilidad: un botón pequeño, un contraste bajo o una espera sin respuesta visible se experimentan antes que cualquier problema interno. También es donde se decide qué información se envía al servidor, así que una validación ausente aquí se paga después. En una wiki como esta, el frontend convierte archivos Markdown en páginas legibles.

## Ejemplo

La ficha de una entrada: el HTML semántico da título y secciones, el CSS aplica el tema claro u oscuro, y una pequeña isla de JavaScript activa el buscador. El contenido puede generarse durante el build y aun así desplegarse como frontend.

## Se confunde con

No es fullstack: esa palabra incluye también servidor y datos; el frontend es solo la capa visible. Tampoco es igual a «todo lo que veo»: una respuesta del servidor puede pintarse en el navegador sin que el frontend la haya calculado. Y no es solo diseño: la apariencia es parte, pero la lógica de interacción y el estado de la interfaz también lo son.
