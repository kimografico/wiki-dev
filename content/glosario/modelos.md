## Definición

Estructuras de datos con reglas que describen la información que maneja una aplicación.

## Por qué importa

Sirven para validar entradas y compartir un vocabulario entre frontend, backend y base de datos.

## Ejemplo

```ts
interface Usuario { id: string; email: string; activo: boolean }
```

## Se confunde con

No es un modelo de IA: aquí modelo es la representación de datos, no un modelo entrenado.
