## Definición

Estructuras de datos con reglas que describen la información que maneja una aplicación.

## Por qué importa

Sirven para validar entradas y compartir un vocabulario entre frontend, backend y base de datos.

## Ejemplo

```ts
interface Usuario { id: string; email: string; activo: boolean }
```

## Se confunde con

- **Modelo de IA**: en Machine Learning, un modelo es el resultado de entrenar con datos y sirve para predecir; aquí es una estructura que describe y valida información.
- **No es una etiqueta del catálogo**: en esta wiki se documenta con la etiqueta backend.
