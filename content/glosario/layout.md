## Definición

Estructura visual y de código que envuelve varias páginas y define zonas comunes como cabecera y pie.

## Por qué importa

Centraliza decisiones repetidas y evita que cada ficha tenga una copia distinta del mismo marco.

## Ejemplo

Un layout de Astro con slot para el contenido de cada entrada.

## Se confunde con

No es una plantilla de datos: el layout organiza la presentación; la plantilla define campos y secciones.
