## Definición

Interfaz de línea de comandos: programa que se maneja escribiendo órdenes en una terminal.

## Por qué importa

Es la forma más reproducible de automatizar tareas de desarrollo porque se puede guardar en scripts y ejecutar en CI.

## Ejemplo

```bash
npm run validate
```

## Se confunde con

No es una GUI: la CLI usa texto y argumentos; la interfaz gráfica usa ventanas y pulsaciones.
