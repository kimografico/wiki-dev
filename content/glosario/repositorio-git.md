## Definición

Directorio que contiene el historial completo de un proyecto, con commits, ramas y referencias.

## Por qué importa

Permite volver a cualquier estado, bisecar un error y coordinar el trabajo de varias personas.

## Ejemplo

```bash
git clone https://github.com/kimografico/wiki-dev.git
```

## Se confunde con

No es el patrón Repository: aquí es el almacén de Git; allí es una abstracción de acceso a datos.
