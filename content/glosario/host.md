## Definición

Equipo, proceso o servicio que aloja y sirve una aplicación o un dominio.

## Por qué importa

Define quién responde una petición y dónde vive realmente el código en ejecución.

## Ejemplo

GitHub Pages actúa como host de esta wiki; `localhost` es el host de la máquina de desarrollo.

## Se confunde con

No es dominio: el dominio es el nombre; el host es el sistema que atiende ese nombre.
