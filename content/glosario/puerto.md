## Definición

Número lógico que identifica un servicio dentro de una máquina para que las conexiones lleguen al proceso correcto.

## Por qué importa

Explica por qué dos servidores localizados no pueden escuchar en el mismo puerto a la vez.

## Ejemplo

```bash
npm run dev # abre http://localhost:3000/
```

## Se confunde con

No es un host: el host es la máquina; el puerto es la puerta concreta dentro de esa máquina.
