## Definición

Comentario convencional en el código que marca una tarea pendiente o una decisión pospuesta.

## Por qué importa

Deja constancia de una deuda pequeña en el lugar exacto donde aparece, sin bloquear el cambio actual.

## Ejemplo

```ts
// TODO: soportar paginación cuando la API la ofrezca
```

## Se confunde con

No es una issue: el TODO vive en el código; la issue vive en el gestor de trabajo y tiene seguimiento.
