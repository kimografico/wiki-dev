## Definición

En el vocabulario interno de BBVA, la capa host es una de las denominaciones de capa del sistema, junto a capa front, capa ASO y capa APX. Nombra una responsabilidad dentro de ese vocabulario; no es el término público Host ni un producto instalable. Su documentación es privada, así que aquí se fija el modelo mental, no una sintaxis ni una versión.

## Por qué importa

Al leer material del banco, la capa host aparece con un sentido propio. Reconocerla como nombre de capa evita interpretarla como la máquina que responde una web o como un mainframe en abstracto. Las cuatro denominaciones pertenecen al mismo vocabulario interno.

## Ejemplo

Si un documento interno nombra la capa host junto a la capa APX, está usando el vocabulario de capas del banco. No está describiendo una petición HTTP ni la cabecera `Host` de una solicitud.

## Se confunde con

- **Host**: en documentación pública es el dispositivo o servicio que aloja y atiende una aplicación o un dominio. La capa host es una denominación interna; compartir la palabra no las hace equivalentes.
- **Mainframe**: es un equipo de alta capacidad para transacciones masivas. Sirve como analogía al hablar de sistemas centrales, no como definición de la capa interna.
- **Capa front, ASO y APX**: son denominaciones distintas del mismo vocabulario; ninguna es sinónimo de las demás.
