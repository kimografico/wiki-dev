## Definición

Archivo de texto que sirve como puerta de entrada de un proyecto: qué es, cómo se ejecuta y dónde está el detalle.

## Por qué importa

Es la primera documentación que se lee y la que decide si alguien puede reproducir el entorno.

## Ejemplo

El README de esta wiki con comandos, estructura y enlace a `specs/`.

## Se confunde con

No es la spec: el README resume y orienta; la spec fija decisiones obligatorias.
