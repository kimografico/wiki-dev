## Definición

Bloque de código con nombre que recibe parámetros, realiza una tarea y puede devolver un resultado.

## Por qué importa

Es la unidad mínima de reutilización y de test; una función bien delimitada hace que el resto del sistema sea más predecible.

## Ejemplo

```js
function doble(n) { return n * 2; }
```

## Se confunde con

No es un método: la función es independiente; el método está asociado a un objeto o clase y recibe `this`.
