## Definición

Comprobación estática de tipos que detecta usos incorrectos antes de ejecutar el programa.

## Por qué importa

Es la primera red de seguridad en un proyecto TypeScript y suele ejecutarse en CI.

## Ejemplo

```bash
npm run check
```

## Se confunde con

No es un test: el typecheck comprueba formas; el test comprueba comportamiento.
