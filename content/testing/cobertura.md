## Qué es

Porcentaje de líneas, ramas, funciones y sentencias del código que han sido ejecutadas por los tests.

## Para qué sirve

Señala zonas sin comprobar, no garantía de corrección: es una herramienta de priorización.

## Tipos de prueba

Unitaria de lógica pura, de integración entre módulos y de componentes con DOM simulado.

## Ejemplo

```bash
npm run test:coverage
```
