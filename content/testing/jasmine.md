## Qué es

Framework de pruebas de JavaScript con sintaxis describe/it y expectativas integradas.

## Para qué sirve

Fue la base de muchas herramientas posteriores y sigue presente en proyectos Angular antiguos.

## Tipos de prueba

Unitarias de funciones y servicios con espías propios.

## Ejemplo

```js
describe('doble', () => { it('duplica', () => expect(doble(2)).toBe(4)); });
```
